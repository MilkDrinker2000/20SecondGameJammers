# Game Flow

- The first screen is a black screen, with some text that pops up. Maybe a line that sort of sets up the situation, something like: “I can feel it… I don’t have much longer…”
  - Audio is soft and melancholy.
- The doctor comes into focus and says a message about having 20 seconds to live, and that you might want to say your last words to the person you care about.
- The phone comes into focus.
- The contact menu comes up. This is technically the title/main menu.
- Select a contact to send a message to.
- The text chat shows on the phone, with the message greyed out in the input box.
- As the user aims at the keys, correctly typed letters will become black.
  - The cursor will be a finger.
  - Wrongly pressed keys will cause:
    - The input text box to turn red.
    - The finger to be damaged.
    - A sound effect.
    - The right key to press to light up/come into focus.
- Once the message is correctly typed in full, send the message in the chat.
- The screen will go black, and a message will show based on success or failure.
